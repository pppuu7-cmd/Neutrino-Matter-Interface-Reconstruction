# Preregistration 0077 — G9 turning-point / monotone-segment global radial kernel

Date frozen: 2026-09-07
Parent: 0076 `SCIENTIFIC_FAIL_G9_GLOBAL_MULTIIMAGE_KERNEL` because scan-grid sign changes miss narrow `|y|<=r` preimages near radial extrema/caustics.

## Scientific question

Can the already pinned extended-Sun Model-S lens be integrated globally and grid-independently by explicitly partitioning the signed radial mapping into monotone segments at all radial turning points, eliminating the narrow-caustic miss that invalidated 0076?

This is still a geometry/method gate only. It must not inspect/reuse the 0075 finite-source utility map and must not select a named astrophysical source.

## Frozen algorithm

1. Evaluate the signed map on `combined_scan_grid()` only to bracket **turning points**, not to directly decide accepted preimages.
2. On each adjacent scan interval estimate the derivative sign using symmetric/one-sided finite differences evaluated from the continuous signed-map function. Bracket every derivative-sign reversal; refine each turning point by bisection on a derivative surrogate using a fixed relative step `h=max(1e-9,1e-5*b)` clipped to the validated domain.
3. Insert domain boundaries, all refined turning points, and the generating root. This partitions the domain into monotone segments. Verify monotonicity independently at 9 interior Chebyshev-like control points per segment; any sign reversal not explained by a boundary turning point is `BLOCKED_G9_TURNING_POINT_KERNEL` rather than silently subdivided after result inspection.
4. On each validated monotone segment solve `y=0`, `y=+r`, and `y=-r` whenever endpoint values bracket the target. The accepted subset `|y|<=r` is then determined from those exact monotone-segment crossings. Union adjacent subsets and sum each annulus once.
5. Repeat with a stricter derivative surrogate step `h/2` and with the base scan grid once bisected. These are validation replicas, not alternate answers.

## Prospective criteria

All are frozen before any 0077 result:

1. generating-root recovery `<=1e-10` in `b/Rsun`; all roots unique to `1e-9`;
2. every segment passes the frozen 9-point monotonicity audit;
3. cumulative accepted area finite, non-negative, non-decreasing with `r`, and `<=pi R_sun^2(1+1e-10)`;
4. for `b0=0.024`, exact one-ring containment/reproduction at receiver radii 1, 10, 100 m within **0.5%**;
5. base vs bisected scan-grid cumulative area agrees within **0.5%** for every frozen radius/control distance;
6. nominal derivative step vs half-step cumulative area agrees within **0.5%** for every frozen radius/control distance;
7. no missing crossing/ambiguous monotone segment may be repaired by lowering thresholds or adding result-selected grid points.
