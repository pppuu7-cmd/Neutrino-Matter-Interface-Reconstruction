## Scientific task
Recover the left-panel 95% CL B-L Yukawa upper-bound curve(s) directly from vector drawing commands, with an explicit EPS-coordinate -> `(lambda, |alpha_tilde|)` calibration. No rasterization or point reading by eye is permitted.

## Frozen extraction method
1. Parse the EPS command stream directly. Track current RGB color, line width, and every stroked path generated by M/L/SN commands.
2. Identify the two plot panels from black axis-frame/tick geometry, not from screenshot pixels.
3. Calibrate the left-panel x and y coordinates using vector tick positions together with the printed axis tick values in the primary figure. Both axes are logarithmic; fit affine maps in `log10(lambda/m)` and `log10(|alpha_tilde|)` from all usable major ticks, not from two hand-selected endpoints.
4. Accept a calibration only if the maximum back-projection residual of the vector major-tick positions is <= `2e-3` decades on each axis. Failure is `SCIENTIFIC_FAIL_VECTOR_CALIBRATION` for this route.
5. Identify candidate exclusion curves by exact EPS color/path identity and panel clipping. Preserve source curve labels separately (EW, EW94, EW99, Princeton, Moscow, LLR); do not silently merge them.
6. For the NMIR B-L envelope, use the pointwise strongest published upper bound among the explicitly identified primary curves only after each curve's vector identity is validated. Do not infer regions between disconnected path segments except by monotone interpolation within the same continuous path.
7. Convert `|alpha_tilde|` to `|g_BL|` only with the already frozen helper `|g_BL| = 2.70463357586823e-19*sqrt(|alpha_tilde|)` and `m_V[eV] = 1.973269804e-7/lambda[m]`.

## Validation
- The extracted vector path must reproduce its own EPS endpoints/turning points under round-trip coordinate transformation to <= `1e-9` EPS coordinate units apart from serialization rounding.
- The derived curve must remain within the source panel domain and must not use text glyph strokes or axis/tick strokes.
- A machine-readable ledger must record path color, path index/segment, source hashes, axis-fit coefficients/residuals, exclusion sense, and transformed `(m_V,g_BL)` points.
- A secondary contour may be used only as a regression diagnostic and cannot rescue a failed primary calibration.
