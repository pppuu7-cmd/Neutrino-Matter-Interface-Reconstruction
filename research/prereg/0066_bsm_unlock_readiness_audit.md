# NMIR preregistration 0066 — formal BSM unlock readiness audit

Date frozen: 2026-09-07

Parent authority: iteration 0065 and reconciled funnel. This iteration is an architecture/readiness audit only; it does not test, endorse or optimize any BSM/light-mediator mechanism.

## Scientific question
Are the principal Standard-Model passive-target residuals now sufficiently **closed, quantitatively strong-negative, or explicitly evidence-blocked** that NMIR may open a constraints-only BSM/light-mediator branch without pretending unresolved SM physics has been solved?

## Frozen unlock criteria
BSM may be reclassified from `LOCKED` to `UNLOCKED_FOR_CONSTRAINT_LEDGER_ONLY` only if all conditions hold:
1. every co-primary passive-SM branch has a current F10 state backed by immutable provenance;
2. no remaining SM branch is both quantitatively unbounded and immediately actionable with presently available primary inputs;
3. every OPEN/BLOCKED residual is explicitly named, with the exact missing theorem/evidence/input and a guard against silently treating it as closed;
4. broad no-free-lunch gates have been applied before any BSM composition: fixed mass/column, integrated resonance strength, finite source/Liouville, stored/pump energy accounting, sum-rule/extensivity constraints;
5. opening BSM does not authorize a solution claim: the first BSM stage is only a constraints ledger over mediator mass/coupling/operator structure and existing laboratory/astrophysical/cosmological exclusions;
6. no BSM gain may be multiplied with an unresolved SM gain or detector gain.

If any principal SM residual is still quantitatively unbounded **and actionable with existing authority**, BSM remains locked and that SM gate stays higher priority.

## Prospective classifications
1. `PASS_UNLOCK_BSM_CONSTRAINT_LEDGER_ONLY`
   - all principal SM residuals are either closed/strong-negative or explicit blockers not presently actionable with available authority; no unresolved actionable SM gate outranks a constraints-only BSM audit.

3. `BLOCKED_RECOVERY_OR_AUTHORITY_GAP`

## Mandatory guards
- `UNLOCKED_FOR_CONSTRAINT_LEDGER_ONLY` is not `BSM_PASS`, not evidence for a new force, and not permission to tune couplings to NMIR before external constraints are frozen.
- The G3 absolute contact-current residual must remain explicitly OPEN unless a new theorem closes it.
- G2/G8 evidence blockers are not physical impossibility statements.
- Documentation maturity alone cannot satisfy an unlock criterion.
- Readiness receives no automatic increase merely for changing branch status.
