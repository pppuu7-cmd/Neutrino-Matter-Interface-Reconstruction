## Frozen monotone partition

1. Use global boundaries `{1e-4,1}` and the final 0089c turning roots only. No new turning root may be added from area results.
2. Sort these points and form closed monotone branch intervals, sharing only boundary turning points.
3. Confirm each branch orientation with analytic `D_c` at fixed fractional branch probes `{1/16,2/16,...,15/16}`. All non-root probes must have the orientation implied by 0089c. A contradiction is fail-closed; do not subdivide post hoc.
4. Evaluate `y_c` at every branch endpoint and fixed orientation probe. Values must be finite.

## Frozen crossing solver

For each radius `r` and each certified monotone branch:
- solve the three target equations `y_c=0`, `y_c=+r`, `y_c=-r` only when the monotone endpoint range brackets that target;
- use deterministic bisection to x-width `<=1e-12`;
- a turning-point endpoint satisfying a target is owned by the lower-index branch for bookkeeping, while a zero-measure shared endpoint never contributes area twice;
- construct the branch subset satisfying `|y_c|<=r` from endpoint ordering and the solved crossings only;
- merge only exactly adjacent/tolerance-equivalent accepted x intervals (`<=2e-11` endpoint separation) after recording their parent branches; overlapping positive-width accepted intervals from different branches are a scientific contradiction/no-double-counting failure, not silently unioned.

No sign-change scan is allowed to discover accepted intervals. The branch topology is inherited from 0089c.

## Frozen accepted-area definition

For disjoint accepted preimage intervals `[x_lo,x_hi]`, define the incident lens-plane area

`A_acc(r,z) = pi R_sun^2 * sum_i (x_hi_i^2 - x_lo_i^2)`.

This area counts incident annular phase-space once. The dimensionless receiver-area ratio, used only as a geometry diagnostic, is

`K(r,z) = A_acc(r,z) / (pi r^2)`.

`K` is **not** interaction gain, neutrino-energy gain, detector gain or persistent-source time-averaged utility.
